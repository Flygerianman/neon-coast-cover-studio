Neon Coast Cover Studio turns one of your photos and a caption into GTA 6-style cover art, right in the browser. Pick from multi-panel poster layouts, wash the shots in a Vice City neon-sunset grade, and set the caption in bold poster lettering — then export a finished PNG in 1080×1080, 1080×1350, or 1920×1080. It runs fully offline, so your photos never leave your machine.

## Run it

```sh
node serve.ts  # serves on http://localhost:8000
```
